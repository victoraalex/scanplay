# Changelog

All notable changes to ScanPlay are documented in this file.

The format is inspired by [Keep a Changelog](https://keepachangelog.com/), and this project uses semantic versioning style labels.

## [1.2.0] - Unreleased

### Added

- Direction stimulus mode.

### Changed

- Product focus reduced to three primary modes: colors, numbers, and directions.
- Mobile interface updated with a more minimal and professional visual style.
- Session code now uses one shared timed random stimulus flow for the three modes.

### Removed

- Exercise library categories.
- Reactive cone drill.
- Oriented first-touch drill.
- Number pass challenge.
- Conflict/Stroop drill.
- Sequence memory drill.

## [1.1.0]

### Added

- Number stimulus mode.
- Configurable inclusive number range.
- Repository structure with `assets/`, `docs/`, issue templates, README, changelog, and roadmap.

### Changed

- Session logic now uses a generic stimulus flow shared by colors and numbers.

## [1.0.0]

### Added

- First functional version.
- Color stimuli.
- Color selection.
- Configurable fixed interval.
- Configurable session duration.
